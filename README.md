# NEXO SOUND

Painel desktop premium para aumentar o volume global do Windows além do limite de 100%, com equalizador de 9 bandas, efeitos espaciais e limiter/compressor integrado. Construído sobre o Equalizer APO.

## Download

Clique no botão abaixo para baixar o instalador completo. Ele configura tudo automaticamente.

**[⬇️ Baixar NEXO SOUND (Setup)](https://github.com/Jhin1v9/volume-boost-500/releases/download/v2.0.0/NEXO.SOUND.Setup.2.0.0.exe)**

> Execute o arquivo baixado como administrador. O instalador baixa e instala o Equalizer APO, ReaPlugs e o app desktop.

## Funcionalidades

- **Volume Boost**: 0% a 500%
- **Efeitos premium**: Clareza, Ambiente, Surround, Impulso Dinâmico, Reforço de Graves
- **Equalizador manual**: Graves, Médios, Agudos
- **Limiter / Compressor**: ReaComp para evitar que o som estoure
- **13 presets**: Padrão, Geral, Filmes, TV, Transcrição, Música, Voz, Volume Boost, Gaming, Classic, Light, Bass Boost, Streaming
- **Interface glassmorphism** com ícones Lucide

## Como instalar

1. Clique em **[Baixar NEXO SOUND](#download)** acima.
2. Execute o arquivo baixado.
3. Confirme o UAC (permissão de administrador).
4. Aguarde o instalador baixar e instalar o Equalizer APO e o ReaPlugs.
5. Pronto! O app abre automaticamente e o atalho fica na área de trabalho.

## Requisitos

- Windows 10/11 64-bit
- Permissão de administrador
- Conexão com internet durante a instalação

## Avisos

- Não use volumes muito altos (300%+) com fones de ouvido por longos períodos.
- O limiter ajuda a evitar distorção, mas não elimina completamente o ruído de fundo de áudios de baixa qualidade.
